# Event Registration System

## Project Overview
The Event Registration System is a web-based application developed to simplify the process of event registration and booking. It allows users to view events, register for events, manage their bookings, and generate tickets.

## Technologies Used
- **Frontend:** HTML, CSS, Bootstrap
- **Backend:** PHP
- **Database:** MySQL
- **Server:** XAMPP

## Features
- User Registration
- Event Registration
- Event Booking
- View My Bookings
- Cancel Bookings
- Ticket Generation
- Admin Panel
- User Logout

## Database
The project uses MySQL with the database name `event_registration`.

## How to Run the Project
1. Install XAMPP.
2. Copy the project folder into the `htdocs` directory.
3. Start Apache and MySQL from XAMPP.
4. Open phpMyAdmin and import the project database SQL file.
5. Open your browser.
6. Visit `http://localhost/your-folder-name/`.

## Project Purpose
The main purpose of this project is to provide an easy and organized platform for managing event registrations and bookings.

## Developed Using
PHP, MySQL, HTML, CSS and Bootstrap.
